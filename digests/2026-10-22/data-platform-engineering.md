# Google Cloud outage hits UK banks as Databricks and BigQuery ship GA platform features

A Google Cloud regional outage disrupted Revolut and other UK banks, a reminder of concentration risk for platform teams. Separately, Databricks took its AI Runtime generally available and BigQuery's ObjectRef type reached GA for querying unstructured data in SQL, while DataHub and OpenMetadata both shipped releases with security fixes. Much of the rest of the feed was Snowflake stock-ticker noise and near-duplicate vendor press.

## Top stories
- **[Google Cloud London Outage Hits Revolut, UK Banks](https://news.google.com/rss/articles/CBMimgFBVV95cUxNcGxuanVPbjF6V0U2N0s3ak84R3JNVUJhTVBQbGtOUkZ2ZE15YkJMTUF6NWdSVlRtVkFvRldYWFF6amtqLURYTXplYmhDdEdpZlplZmt3cHZ4NW1abWlfTjRBbEpOQzBoMjYySkVvNjFXVTRzYkU1M2l5VFpiWlZnWWhNZmI5UU5OM0F2TklIaEZGYTNzYVhVcFVn?oc=5)** — Technology Org. A Google Cloud outage in its London region disrupted services for Revolut and other UK banks. *Why it matters:* a regional cloud outage hitting financial-services workloads underscores the concentration risk of relying on a single cloud region or provider.
- **[AI Runtime is Generally Available](https://www.databricks.com/blog/ai-runtime-generally-available)** — Databricks Blog. Databricks' AI Runtime (AIR) reached general availability, with a companion post describing a push with NVIDIA to make it easier to fine-tune and customize open models on enterprise data. *Why it matters:* this moves a core GPU-workload capability from preview to production-ready inside the platform.
- **[BigQuery ObjectRef now GA: Build multimodal data platforms for conversational analytics entirely in SQL](https://cloud.google.com/blog/products/data-analytics/analyze-unstructured-data-in-bigquery-with-objectref/)** — Google Cloud. ObjectRef lets teams reference images, video, audio and documents directly in BigQuery SQL, removing the need to stitch external inference pipelines back into the warehouse. *Why it matters:* closes a long-standing gap between structured and unstructured data handling in the primary analytics engine.

## Releases & tools
- **[DataHub 1.8.0](https://github.com/datahub-project/datahub/releases/tag/v1.8.0)** — Ships a documented breaking change for context docs views and an N+1 query fix for container entity counts; its release-candidate also backported authorization security fixes.
- **[OpenMetadata 2.0.6](https://github.com/open-metadata/OpenMetadata/releases/tag/2.0.6-release)** — A maintenance release that fixes security vulnerabilities in application dependencies and content handling, alongside ingestion, search and governance fixes.
