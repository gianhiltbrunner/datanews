# DuckDB 2.0 ships its biggest release yet as a Google Cloud outage hits UK banks

DuckDB's 2.0 LTS launch was the clearest single story of the day, already drawing fresh benchmark comparisons against Polars and Spark. Elsewhere, a Google Cloud regional outage disrupted UK banks, Databricks and BigQuery both took major capabilities to general availability, and the analytics-engineering world kept debating which of several incomplete metrics standards should win out.

## Top 5 across domains
- **[Data Engineering]** **[DuckDB 2.0.0 LTS "Cinnamon Teal"](https://duckdb.org/2026/10/21/announcing-duckdb-200)** — DuckDB's biggest feature release yet, adding a server protocol, async I/O, a VARIANT type, triggers and an agent mode.
- **[Data Platform Engineering]** **[Google Cloud London Outage Hits Revolut, UK Banks](https://news.google.com/rss/articles/CBMimgFBVV95cUxNcGxuanVPbjF6V0U2N0s3ak84R3JNVUJhTVBQbGtOUkZ2ZE15YkJMTUF6NWdSVlRtVkFvRldYWFF6amtqLURYTXplYmhDdEdpZlplZmt3cHZ4NW1abWlfTjRBbEpOQzBoMjYySkVvNjFXVTRzYkU1M2l5VFpiWlZnWWhNZmI5UU5OM0F2TklIaEZGYTNzYVhVcFVn?oc=5)** — a regional cloud outage disrupted services for Revolut and other UK banks.
- **[Data Platform Engineering]** **[AI Runtime is Generally Available](https://www.databricks.com/blog/ai-runtime-generally-available)** — Databricks' AI Runtime reached GA, paired with a push to ease fine-tuning open models on enterprise data.
- **[Data Platform Engineering]** **[BigQuery ObjectRef now GA](https://cloud.google.com/blog/products/data-analytics/analyze-unstructured-data-in-bigquery-with-objectref/)** — BigQuery can now reference unstructured data like images and video directly in SQL, closing a structured/unstructured gap.
- **[Analytics Engineering]** **[One Metric, Four Standards](https://medium.com/@alex.nykolaiszyn/one-metric-four-standards-77fc3c5e2007?source=rss------dbt-5)** — ODCS, ODPS, Ossie and dbt's MetricFlow each solve only part of the problem of defining a metric consistently.
