# An opinion piece argues dbt-core is being deprecated as dbt 2.0 goes proprietary

A quiet window for analytics engineering: the one piece worth flagging is an opinion post claiming dbt's default install has turned proprietary with dbt-core being deprecated, while most of the rest of the feed was tutorials, an unrelated self-help post matched on the "DBT" keyword, and routine Lightdash patch releases.

## Top stories
- **[The Hidden Cost of dbt 2.0's Proprietary Turn](https://medium.com/@m.awais1060/the-hidden-cost-of-dbt-2-0s-proprietary-turn-d4c939e9479b?source=rss------dbt-5)** — Medium. The piece argues that dbt's default install is now proprietary, that dbt-core is being deprecated, and that teams still on dbt Core v1 have a limited window to migrate. *Why it matters:* if borne out, this is the kind of licensing shift that forces every team on open-source dbt-core to re-plan its transformation stack — worth watching for confirmation from dbt Labs itself.
