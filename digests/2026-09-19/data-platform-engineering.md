# Databricks' RADAR flags 'gray failures' as clouds push cross-cloud lakehouses

Today's real news was buried under a pile of Snowflake stock-ticker filler and CEO-commentary wire stories. Underneath it: Databricks detailed an anomaly-detection system for the partial outages that conventional monitoring misses, Google Cloud previewed cross-cloud caching for its "borderless Lakehouse," and Snowflake shipped a way to query tables registered in other catalogs without moving the data.

## Top stories
- **[RADAR: Catch gray failures with anomaly detection](https://www.databricks.com/blog/radar-catch-gray-failures-anomaly-detection)** — Databricks Blog. RADAR is a four-stage pipeline — metrics collection, unsupervised anomaly detection (via a streaming model called SPOT), deduplicated alerting, and AI-assisted root-cause dashboards — built to catch "gray failures," partial outages (like a checkout bug hitting only card payments) that never trip conventional monitoring. Databricks reports it cut incident-discovery time by 95% with over 90% precision, and that the same approach applies to billing anomalies and model-performance drops, not just outages. *Why it matters:* turns a chronic blind spot — degradations dashboards don't flag — into a minutes-not-days detection problem.
- **[Accelerating the borderless Lakehouse: Announcing preview of cross-cloud caching](https://cloud.google.com/blog/products/data-analytics/borderless-lakehouse-cross-cloud-caching-and-connections/)** — Google Cloud, Data Analytics. A public preview lets query engines and AI agents reach governed data cached across clouds — S3, Azure Data Lake Storage, and others — without first copying it into BigQuery. *Why it matters:* cross-cloud lakehouse access has mostly meant slow, ungoverned reads; caching close to the compute is the piece that's been missing.
- **[Snowflake Catalog Linked Database (CLD): Breaking Data Silos Without Moving Data](https://medium.com/snowflake/snowflake-catalog-linked-database-cld-breaking-data-silos-without-moving-data-42727f9e7085?source=rss----34b6daafc07---4)** — Snowflake Engineering. CLD lets teams reference tables registered in other catalogs — Unity Catalog, AWS Glue, Snowflake Open Catalog — from inside Snowflake without copying the data. *Why it matters:* directly targets the "which catalog is the source of truth" problem multi-engine lakehouse shops keep running into.
