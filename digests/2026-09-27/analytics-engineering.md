# Databricks buys Row Zero for Genie as teams plan dbt Core v2 migrations

The 72-hour window was thin on substantive newsletter and blog writing, but produced two concrete developments worth tracking: Databricks acquiring spreadsheet startup Row Zero to feed its Genie AI agent, and a practical walkthrough for moving existing Snowflake dbt projects onto the new Rust-based dbt v2. A Show HN project applying DuckDB's own SQL parser to dbt-style builds rounded out the day's best reading.

## Top stories
- **[Databricks acquires Row Zero, gives Genie a spreadsheet](https://news.google.com/rss/articles/CBMiowFBVV95cUxQR2R6YjVkVmxSTUdwVl9XZ0tlaklUTjZSRzlWaEc5VGhwZnROSF8xN2ozYXN3cUk3ZUwzbGdIUGM4TXNVUF9kb3BHUXlvYldVY1RzZXY3bk5GTVpVQUQ1bDZkTzFMbnNQWjVobXVjaUNLSFZXQlB3R1pFSHRncEd5ZVY0M1dNYUJpMVBwVy1DYjlUSEdneXdISDhoQ1FTYnM1MzZr?oc=5)** — Google News (dbt Labs / semantic layer). Databricks acquired spreadsheet startup Row Zero, adding spreadsheet-native interaction to its Genie AI agent for querying enterprise data. *Why it matters:* pushes Databricks further into the BI/spreadsheet layer that analytics engineers hand data off to, rather than leaving it to dedicated BI vendors.
- **[From dbt Core v1 to dbt v2 on Snowflake: A Practical Migration Guide](https://medium.com/snowflake/from-dbt-core-v1-to-dbt-v2-on-snowflake-a-practical-migration-guide-4eb137573a1f?source=rss------dbt-5)** — Snowflake Builders Blog (Medium). Walks through preparing an existing Snowflake dbt project for the new Rust-based dbt v2, including validating compatibility and handling gaps in static analysis. *Why it matters:* concrete steps for teams who will be pushed off dbt Core v1 as the ecosystem moves to the Rust rewrite.
- **[Show HN: Minimal dbt-style SQL builds with DuckDB and Make](https://github.com/ltrgoddard/duckdb.mk)** — Hacker News. A ~250-line tool uses DuckDB's `json_serialize_sql` function to parse SQL into an AST, replicating dbt's core dependency-resolution between named queries with just DuckDB and Make. *Why it matters:* a lightweight option for teams who want dbt's referencing model without its configuration overhead.
