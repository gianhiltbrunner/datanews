# AWS tightens cross-Region data governance as agents write a growing share of pipelines

A quiet day across the three domains, with the clearest signal in platform infrastructure: AWS extended Lake Formation's governance across regions, and ClickHouse published a migration case study with real performance numbers. The agent theme ran through every domain, from Google's Data Agent Kit reaching GA to a Carnegie Mellon researcher's case for why data agents still can't do real analysis on their own.

## Top 5 across domains
- **[Data Platform Engineering]** [AWS Lake Formation now supports cross-Region fine-grained data access](https://aws.amazon.com/blogs/big-data/enable-cross-region-fine-grained-data-access-with-aws-lake-formation-and-trusted-identity-propagation/) via Trusted Identity Propagation, letting governed S3 and Redshift data be queried from another region as the actual user, with per-user CloudTrail auditability.
- **[Data Platform Engineering]** [Shipsidekick's migration from Neon to ClickHouse Managed Postgres](https://clickhouse.com/blog/shipsidekick-neon-to-clickhouse-managed-postgres) cut CPU usage from 100% to 5–10% and made queries roughly 10x faster, in a single weekend.
- **[Data Engineering]** [Google's Data Agent Kit reached general availability](https://www.infoq.com/news/2026/10/data-agent-kit-ga/?utm_campaign=infoq_content&utm_source=infoq&utm_medium=feed&utm_term=AI%2C+ML+%26+Data+Engineering), connecting coding agents to 15+ Google Data Cloud services via MCP tools and skills, with separate advisory and enforced (IAM) guardrail layers.
- **[Data Engineering]** [Netflix built Quasar](https://netflixtechblog.com/beyond-api-compatibility-building-a-tool-to-measure-the-blast-radius-of-library-changes-9474f2fd4f90?source=rss----2615bd06b42e---4), a tool that measures the blast radius of a shared-library change by connecting the API diff to the consumer repositories that actually reference it.
- **[Analytics Engineering]** [Carnegie Mellon's Shreya Shankar explains why data agents fall short at real analysis](https://roundup.getdbt.com/p/can-data-agents-do-real-analysis), what a semantic layer changes about that, and how to evaluate LLM outputs you can trust.
