# Spanner Omni Goes GA as Aurora Adds Native Iceberg and Parquet Queries

Google Cloud took Spanner Omni — a deploy-anywhere, multi-model version of Spanner — to general availability, while AWS let Aurora PostgreSQL query Iceberg and Parquet data lake files directly without ETL. Microsoft used FabCon Europe in Barcelona to detail a wave of Fabric governance and deploy-at-scale features, Azure confirmed several VM series are heading into retirement, and OpenMetadata 2.0.3 shipped fixes for a certificate-verification bypass and a SQL-injection flaw.

## Top stories
- **[Spanner Omni, now GA: A distributed, multi-model database that you can deploy anywhere](https://cloud.google.com/blog/products/databases/spanner-omni-deploy-anywhere-version-of-spanner-is-now-ga/)** — Google Cloud. Spanner Omni, the deploy-anywhere version of Spanner, is now generally available for on-premises or other-cloud deployment, combining SQL, graph, key-value, full-text and vector search in one interoperable multi-model database. *Why it matters:* extends Spanner's distributed-SQL model outside Google Cloud at GA for the first time.
- **[Aurora PostgreSQL now supports querying of Apache Iceberg and Parquet data](https://aws.amazon.com/about-aws/whats-new/2026/09/aurora-postgresql-query-apache-iceberg-and-parquet/)** — AWS What's New. Aurora PostgreSQL can now query data stored in Apache Iceberg and Parquet formats in a data lake directly from existing PostgreSQL applications, without building ETL pipelines to copy data in first. *Why it matters:* removes a common category of lakehouse-to-operational-database pipeline work.
- **[Fabric September 2026 Feature Summary](https://community.fabric.microsoft.com/t5/Fabric-Updates-Blog/Fabric-September-2026-Feature-Summary/ba-p/5325825)** — Microsoft Fabric Blog. Coinciding with FabCon and SQLCon Europe in Barcelona, Microsoft's September Fabric roundup covers governance, CI/CD and data-engineering updates alongside AI-powered experiences and real-time intelligence additions. *Why it matters:* governance and deployment tooling maturing is a signal Fabric adoption is moving past pilot projects.
- **[Retirement: Dv3, Dsv3, Ev3, and Esv3 Azure VMs](https://azure.microsoft.com/updates?id=572346)** — Azure Updates. Microsoft is retiring the Dv3, Dsv3, Ev3 and Esv3 Azure VM series on November 15, 2029, while the NVv3 and NVv4 GPU VM series [were retired immediately](https://azure.microsoft.com/updates?id=573414) on September 30, 2026. *Why it matters:* teams running data platform workloads on these series need a migration path before the deadlines.
- **[Resolving PostgreSQL replication lag with heartbeat tables in change data capture scenarios](https://aws.amazon.com/blogs/database/resolving-postgresql-replication-lag-with-heartbeat-tables-in-change-data-capture-scenarios/)** — AWS Database Blog. Shows how to diagnose and fix PostgreSQL CDC replication lag that builds up even when the source isn't under heavy load, using heartbeat tables with AWS DMS or Debezium and monitoring replication slot health via CloudWatch. *Why it matters:* a counterintuitive failure mode — lag despite low load — that's easy to misdiagnose.
