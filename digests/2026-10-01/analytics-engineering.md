# An Agent Inherited More Access Than Its User — and Nearly Leaked Data

A Medium post on AI agents inheriting broader access than the people asking them questions set the tone for this roundup, alongside a piece on bringing BI dashboards into git as "dbt Charts" and a GCP/dbt/ML platform-modernization case study from Rebtel. Cube shipped a minor release adding query-level join hints and multi-tenant compiler sharing, while a $1.5M pre-seed for an "agent-first" semantic layer pointed to where funding is flowing next.

## Top stories
- **[One Shared Role Away From a Data Leak](https://npogeant.medium.com/one-shared-role-away-from-a-data-leak-22cc2925371b?source=rss------analytics_engineering-5)** — Medium. Argues that when an AI agent is wired into analytics tooling through a shared service role, it inherits broader access than the individual actually asking the question, turning a routine query into a potential leak. *Why it matters:* a concrete governance failure mode as teams wire agents directly into warehouses and BI layers.
- **[dbt Charts: What Happens When Dashboards Become Code](https://medium.com/@sendoamoronta/dbt-charts-what-happens-when-dashboards-become-code-6f39e691ad26?source=rss------dbt-5)** — Medium. Describes dbt Charts, which brings BI dashboards into Git with CI/CD, lineage and impact analysis, treating chart definitions as version-controlled code. *Why it matters:* extends the "everything as code" pattern from models to the dashboards built on top of them.
- **[Modernizing Rebtel's Data Platform: A GCP, dbt and Machine Learning Case Study](https://medium.com/@arhamsheikh2250/modernizing-rebtels-data-platform-a-gcp-dbt-and-machine-learning-case-study-5babb6c5a295?source=rss------dbt-5)** — Medium. A case study of migrating Rebtel's data platform onto GCP with dbt and machine learning as the stack grew in tools, pipelines and reporting requirements. *Why it matters:* a real-world account of the incremental complexity modern data platforms accumulate.
- **[Motley raises $1.5M pre-seed for agent-first semantic layer](https://news.google.com/rss/articles/CBMilwFBVV95cUxOTVdvQ2l1T2xVSmZ3aHdlOVBvdlBtVzVtaGoyd1FfQkdaY1ZsZDA5eUpOZjZEclVwQkZlZUdWRVRhcEN5QlFYYkxBSkRxOTR2NWlzaFJjanp5bGtoMGVtbFQtVFFjaXJEbzR0a2haMXFYb3BNN3NZWWdQeWFEb1g5QmFEbGJsMzIwWWxoWUxKTVNNbHlwdzdv?oc=5)** — Dealroom via Google News. Motley raised a $1.5M pre-seed round for what it calls an "agent-first" semantic layer. *Why it matters:* another signal that semantic-layer vendors are repositioning around AI agents as the primary consumer, not dashboards.

## Releases & tools
- **[v1.7.48](https://github.com/cube-js/cube/releases/tag/v1.7.48)** — Cube's latest release requires explicit `accessPolicy` member-level includes/excludes in the schema compiler and adds shared compiler state across tenants via `CUBEJS_COMPILER_MULTI_TENANT_SHARING`, on top of date-filter and MSSQL boolean-rendering bug fixes.
