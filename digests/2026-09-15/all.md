# dbt 2.0 lands as platforms shift governance from access to meaning

dbt's 2.0 release is the day's clearest marker: agent skills installable from packages, native Databricks metric views, and a CLI split into proprietary and open-source builds. Around it, the platform vendors spent the window on governing definitions and agent playbooks rather than storage, while Databricks loosened a long-standing constraint on stateful streaming. Data engineering itself was quiet, with the best material arguing for fewer moving parts — durable workflows on the Postgres you already run.

## Top 5 across domains
- **[Analytics Engineering]** **[dbt 2.0.0](https://github.com/dbt-labs/dbt/releases/tag/v2.0.0)** — released September 14, 2026: AgentSkills-format `SKILL.md` directories installable from packages behind a new `ai_provider` flag, native Databricks metric view materializations, a rebuilt ClickHouse path via `adbc_clickhouse`, and the CLI rebranded to `dbt` and `dbt-oss`.
- **[Data Platform Engineering]** **[On-Demand State Repartitioning for Spark Structured Streaming](https://www.databricks.com/blog/announcing-demand-state-repartitioning-apache-sparktm-structured-streaming-databricks)** — stateful queries can now be resized by setting `spark.sql.streaming.stateStore.partitions` and restarting, with state preserved; requires Databricks Runtime 18+ and the RocksDB state store.
- **[Data Engineering]** **[Implementing Durable Workflows on Postgres Without an External Orchestrator](https://www.infoq.com/articles/durable-workflows-postgres/?utm_campaign=infoq_content&utm_source=infoq&utm_medium=feed&utm_term=AI%2C+ML+%26+Data+Engineering)** — `SKIP LOCKED` for concurrent claiming, primary-key checkpoints for idempotency and heartbeat leases for recovery, with connection pooling and autovacuum as the named limits.
- **[Data Platform Engineering]** **[Semantic Governance in Snowflake: Governing Meaning Not Just Access](https://medium.com/snowflake/semantic-governance-in-snowflake-governing-meaning-not-just-access-eca2674a0d92?source=rss----34b6daafc07---4)** — conflicting numbers come from two defensible definitions rather than bad queries, so definitions need governing as first-class objects.
- **[Data Engineering]** **[Grab's Agent Framework LLM-Kit](https://www.infoq.com/news/2026/09/grab-agent-platform/?utm_campaign=infoq_content&utm_source=infoq&utm_medium=feed&utm_term=AI%2C+ML+%26+Data+Engineering)** — one framework standardising over 500 internal agent services, cutting deployment of a new agent from two weeks to one hour.
