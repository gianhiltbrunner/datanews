# Microsoft's FabCon Europe touches off a wave of Fabric ecosystem launches

Microsoft's FabCon and SQLCon Europe conference in Barcelona drove a flood of Fabric-related announcements from Microsoft and partners including ClickHouse, TomTom and Atlan. Elsewhere, Databricks acquired spreadsheet startup Row Zero, Snowflake and LSEG extended a five-year data partnership, and AWS brought OpenAI's models natively onto Bedrock as managed agents — all buried under a heavy load of Snowflake stock coverage and vendor press releases.

## Top stories
- **[Fabric September 2026 Feature Summary](https://community.fabric.microsoft.com/t5/Fabric-Updates-Blog/Fabric-September-2026-Feature-Summary/ba-p/5325825)** — Microsoft Fabric Blog. Microsoft's monthly Fabric roundup, timed to FabCon and SQLCon Europe in Barcelona, covers governance, CI/CD, data engineering, AI-powered experiences and real-time intelligence updates; the conference also drew a run of partner announcements, including ClickHouse now writing Apache Iceberg tables directly to Microsoft OneLake and a new ClickHouse workload for sub-second analytics on OneLake data. *Why it matters:* Fabric's partner ecosystem is visibly deepening, with real engines (not just connectors) now running natively against OneLake.
- **[Databricks Buys Row Zero for Planned Genie Spreadsheet](https://news.google.com/rss/articles/CBMimgFBVV95cUxPdm9nODJmUFZRYVItbzB2emxjUFNmdVc0OUpYWG5TRHNCT18zUXU0WnZGeWZ5V1ZBclhCRWRyT0RJT1NlWjBWZ250cklKU0xNeEh3aEJGVHhyMFlrYnRqNVpiRWdvVVowNW5uTEx5cENNVWptcnFqU1ZRYV9qelRRazRmM2lnYWZUYTJrMF9Cb3BxWVU1TXd2Y3dB?oc=5)** — quasa.io via Google News. Databricks acquired spreadsheet startup Row Zero, reportedly to build into a planned "Genie Spreadsheet" product. *Why it matters:* another sign lakehouse vendors want the spreadsheet interface as a first-class front end for AI-assisted analytics, not just BI dashboards.
- **[LSEG and Snowflake expand collaboration to connect trusted financial data with cloud-native AI workflows](https://news.google.com/rss/articles/CBMijgFBVV95cUxPZldVdDJEcmhRSDNNOHFFWmNicFZtNmQ1OFVHdW9hbDRMaXgzSFY2NmIxZXJXOGJCVFBQZGZiUldZOFFmUEtEd0VieW82MVEwNVROb2F2S0JYTXAxMHJWM3RmSXVBSG9Pbm5XTW9iQm5rNUZxNl8wdThvLTZkSVcyTFNjRGNQcWczelNiTGdn?oc=5)** — Snowflake, via Google News. LSEG and Snowflake announced an expanded five-year enterprise-wide collaboration to connect LSEG's financial data with Snowflake's AI Data Cloud. *Why it matters:* a large, multi-year anchor customer deal for Snowflake in financial services data.
- **[Amazon Bedrock Managed Agents, powered by OpenAI, is now available in preview](https://aws.amazon.com/about-aws/whats-new/2026/09/bedrock-managed-agents-preview/)** — AWS What's New. AWS and OpenAI jointly built Bedrock Managed Agents on a customized, AWS-native version of OpenAI's Agents API, letting teams run OpenAI-model agents inside AWS with existing identity, permissions and governance controls, and durable sessions that persist state across steps. *Why it matters:* a notable crack in the walled-garden model — AWS is now hosting a competitor's models as a first-class, governed agent runtime.
