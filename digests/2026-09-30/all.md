# FabCon Europe fuels a Fabric ecosystem wave as Databricks buys a spreadsheet startup

Microsoft's FabCon and SQLCon Europe conference set off the day's biggest wave of announcements, with Databricks, AWS and Snowflake each making moves of their own around agents and M&A. On the practitioner side, a SQLAlchemy update broke Great Expectations across every major warehouse backend, and a CodeScene case study reignited debate over what agentic code refactoring at scale actually proves.

## Top 5 across domains
- **[Data Platform Engineering]** Microsoft's FabCon and SQLCon Europe conference in Barcelona drove a wave of Fabric ecosystem announcements — see the [Fabric September 2026 Feature Summary](https://community.fabric.microsoft.com/t5/Fabric-Updates-Blog/Fabric-September-2026-Feature-Summary/ba-p/5325825) — including ClickHouse now writing Iceberg tables straight to Microsoft OneLake.
- **[Analytics Engineering]** [Great Expectations 1.23.2](https://github.com/fivetran/great_expectations/releases/tag/1.23.2) patches breakage from SQLAlchemy 2.1.0 that broke imports, Databricks queries, driverless Postgres URLs, BigQuery float comparisons and SQL Server table detection all at once.
- **[Data Platform Engineering]** [Databricks acquired spreadsheet startup Row Zero](https://news.google.com/rss/articles/CBMimgFBVV95cUxPdm9nODJmUFZRYVItbzB2emxjUFNmdVc0OUpYWG5TRHNCT18zUXU0WnZGeWZ5V1ZBclhCRWRyT0RJT1NlWjBWZ250cklKU0xNeEh3aEJGVHhyMFlrYnRqNVpiRWdvVVowNW5uTEx5cENNVWptcnFqU1ZRYV9qelRRazRmM2lnYWZUYTJrMF9Cb3BxWVU1TXd2Y3dB?oc=5), reportedly bound for a planned "Genie Spreadsheet" product.
- **[Data Engineering]** CodeScene's [agentic refactor of 300,000 lines of C in three weeks for about $4,000](https://www.infoq.com/news/2026/09/agentic-refactoring-case-study/?utm_campaign=infoq_content&utm_source=infoq&utm_medium=feed&utm_term=AI%2C+ML+%26+Data+Engineering) drew practitioner pushback over how much of the result depends on the verification harness.
- **[Data Platform Engineering]** [Amazon Bedrock Managed Agents, powered by OpenAI](https://aws.amazon.com/about-aws/whats-new/2026/09/bedrock-managed-agents-preview/), entered preview, letting AWS customers run OpenAI-model agents natively with AWS identity and governance controls.
