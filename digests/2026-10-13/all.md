# A ClickHouse latency postmortem and an AWS EMR/Glue data-quality merger lead a platform-heavy day

Data platform engineering had the strongest news, with a rigorous ClickHouse latency investigation, native data-quality checks landing in Amazon EMR, and Snowflake's Semantic Studio reaching GA. Data engineering's biggest story was operational — Spotify's account of scaling quality controls around AI-accelerated development — while Polars 2.0 upgraders are hitting silent breaking changes. Analytics engineering was quieter, with a security fix in Cube the most concrete item.

## Top 5 across domains
- **[Data Platform Engineering]** **[Chasing that 32 ms tail latency in ClickHouse](https://clickhouse.com/blog/chasing-32ms-tail-latency-clickhouse)** — ClickHouse's team traced an idle-period latency spike to unbatched metadata packets overflowing a reset TCP congestion window, and fixed it by batching them.
- **[Data Platform Engineering]** **[Bring data quality to your Amazon EMR workloads with Amazon EMR Data Quality built on AWS Glue Data Quality](https://aws.amazon.com/blogs/big-data/bring-data-quality-to-your-amazon-emr-workloads-with-amazon-emr-data-quality-built-on-aws-glue-data-quality/)** — AWS Glue Data Quality is now native in EMR's Spark runtime, usable for inline validation or an Iceberg Write-Audit-Publish workflow.
- **[Data Engineering]** **[Spotify More Than Doubled Monthly Code Changes as AI Accelerated Development](https://www.infoq.com/news/2026/10/spotify-ai-quality-controls/?utm_campaign=infoq_content&utm_source=infoq&utm_medium=feed&utm_term=AI%2C+ML+%26+Data+Engineering)** — Spotify reworked testing, observability, rollback capacity and workload prioritization after AI assistance more than doubled its monthly merged changes.
- **[Data Engineering]** **[Polars 2.0: five things that change when you upgrade, three of them silently](https://dev.to/ground_truth_books/polars-20-five-things-that-change-when-you-upgrade-three-of-them-silently-b38)** — Polars 2.0's default streaming engine silently drops row-order guarantees on operations like left joins, among other quiet behaviour changes.
- **[Data Platform Engineering]** **[Introducing Semantic Studio: The Semantic View IDE](https://www.snowflake.com/content/snowflake-site/global/en/blog/semantic-studio-ga)** — Snowflake's IDE for authoring, debugging and deploying semantic views, with git versioning and CI/CD, is now generally available.
