# Grab's LLM-Kit cuts AI agent deployment from two weeks to one hour

Two real infrastructure teams, Grab and Dropbox, described how they're absorbing AI workloads without just buying more hardware, and DuckDB benchmarked new NVIDIA server silicon against TPC-H. Outside of that, the feeds were dominated by generic Databricks/Fabric marketing, beginner tutorials and recruitment noise.

## Top stories
- **[Grab's Agent Framework LLM-Kit Accelerates AI Agent Production Deployment](https://www.infoq.com/news/2026/09/grab-agent-platform/?utm_campaign=infoq_content&utm_source=infoq&utm_medium=feed&utm_term=AI%2C+ML+%26+Data+Engineering)** — InfoQ. Grab built LLM-Kit, an internal framework standardizing over 500 agent services, centralizing infrastructure, evaluation and secret handling. *Why it matters:* it cut the time to deploy a new AI agent from two weeks to one hour.
- **[Dropbox Outlines How Focusing on Existing Infrastructure Efficiency Can Create Headroom for AI](https://www.infoq.com/news/2026/09/dropbox-datacenter/?utm_campaign=infoq_content&utm_source=infoq&utm_medium=feed&utm_term=AI%2C+ML+%26+Data+Engineering)** — InfoQ. Dropbox described a decade of infrastructure optimization work, spanning forecasting, fleet utilization, storage density and rack-level power, that predates the current AI boom but is now absorbing AI demand. *Why it matters:* it shows AI capacity growth doesn't have to mean new data-center builds.
- **[We got early access to an NVIDIA Vera CPU, so we put it through its paces using DuckDB](https://bsky.app/profile/duckdb.org/post/3mvljyo5rjk23)** — DuckDB (Bluesky). DuckDB ran the full TPC-H workload on an early NVIDIA Vera CPU and compared it against a high-end x86 baseline. *Why it matters:* early independent benchmarks of new server CPUs against a standard analytics workload are rare.
