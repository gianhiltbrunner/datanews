# ASOS customers get a 'hacked' alert referencing a Snowflake instance; shares slide

The window's biggest story is a wave of wire coverage after ASOS app users received push notifications claiming a breach and threatening a leak, with the notification referencing ASOS's "Snowflake instance" and both companies' shares dropping on the news. Elsewhere, real engineering write-ups stood out: Databricks detailed how IFCO runs a large dbt project in production, and Amagi described building a 2,500-channel media metadata graph on Amazon Neptune. ClickHouse also shipped executable UDFs to general availability.

## Top stories
- **[Asos customers receive 'hack' notification threatening leak](https://news.google.com/rss/articles/CBMiiwFBVV95cUxPNF93N0dSNXQtYnBmcXpWeGxnek9TSVpmSS1Qb3FCaXBMYzlxeTVGZ253VS11M0FpYVdYYVdjc2phQm92Zjg0QjBzTXdSTGxHdWdTbEpRVEQ0a1RfSnl3SzdjSXd1bGtVNVpaUXlrQkw2c3ZyQ2VYLWQtSnFFakNoaG94Rk9nWnlMOHlR?oc=5)** — The Guardian (via Google News). ASOS app users were sent a push notification claiming the retailer had been hacked and its data would be leaked, with multiple reports saying the message referenced a compromised "Snowflake instance"; ASOS and Snowflake shares both fell (reports cite drops of roughly 11–13%) as the story spread through wire coverage. *Why it matters:* whether this turns out to be a genuine Snowflake-side compromise or a spoofed/compromised notification channel, it's another case of a retailer's cloud data platform becoming the attack surface that customers actually see.
- **[Scaling and Operating a Large dbt Project on Databricks: IFCO's Data Team on Performance, Visibility, and Debugging](https://www.databricks.com/blog/scaling-and-operating-large-dbt-project-databricks-ifcos-data-team-performance-visibility-and-debugging)** — Databricks Blog. Details how IFCO, which tracks hundreds of millions of reusable packaging crates and pallets, scaled a large dbt project on Databricks, covering how the team got visibility into performance bottlenecks and debugged failures at scale. *Why it matters:* a rare vendor post with specifics from an actual large, long-running dbt-on-Databricks deployment rather than a launch announcement.
- **[Executable UDFs are now generally available on ClickHouse Cloud](https://clickhouse.com/blog/executable-udfs-generally-available-on-clickhouse-cloud)** — ClickHouse Blog. Executable UDFs are now GA on ClickHouse Cloud across AWS, GCP and Azure, with native runtimes, network access, observability, and API/Terraform support. *Why it matters:* lets teams run custom logic inside ClickHouse queries without maintaining a separate service, with the governance hooks (observability, Terraform) needed to run that in production.
- **[Amagi's intelligent media operations with Amazon Neptune](https://aws.amazon.com/blogs/database/amagis-intelligent-media-operations-with-amazon-neptune/)** — AWS Database Blog. Amagi built a Global Metadata Store on Amazon Neptune, modelling billions of media-metadata relationships as an RDF knowledge graph paired with OpenSearch, delivering sub-500ms reads across more than 2,500 channels and 150+ countries. *Why it matters:* a concrete example of graph databases earning their keep at real scale for metadata-heavy, highly interconnected catalogs.

## Releases & tools
- **[Amazon Redshift adds support for creating and refreshing Apache Iceberg materialized views](https://aws.amazon.com/about-aws/whats-new/2026/10/redshift-iceberg-materialized-views)** — AWS. Redshift can now precompute joins and aggregations into a materialized view stored as an Iceberg table in S3, queryable by Athena, Spark, Glue and other Iceberg-compatible engines.
- **[Delta Lake 4.4.1](https://github.com/delta-io/delta/releases/tag/v4.4.1)** — a patch on 4.4.0 that extends safeguards on catalog-managed tables so automatic maintenance can't run dangerous cleanup operations, and fixes a snapshot-construction bug for tables using coordinated commits.
- **[Announcing: Table discovery in OneLake Catalog search](https://azure.microsoft.com/updates?id=573875)** — Azure Updates. From October 15, 2026, Fabric search will return individual tables from semantic models, lakehouses and mirrored databases, searchable by table or column name.
